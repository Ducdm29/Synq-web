## 2. Design direction

Idea: the studio is a quiet light page; each product is its own dark world that takes the page over when you reach it (Kagezan = ink + vermilion, Synq = night + teal). Reference studied: antigravity.google (huge tightly-set headline, white ground, 72 px side margins, pill buttons, stacked sticky product cards). Spirit only; no assets or copy reused.

- **Type**: Inter Tight (variable 400-800, self-hosted woff2: latin, latin-ext, vietnamese). Display 600, tracking -0.05em, leading .94. Sizes: hero `clamp(46px, 11.2vw, 184px)`, section `clamp(40px, 7vw, 112px)`, lede 18-24 px, body 17-18 px.
- **Colour tokens**: ground `#f5f5f3`, ink `#0e0e10`, mute `#55555b`, soft `#e9e9e5`; Kagezan night `#0b0b0c` / ink `#f4f1ec` / red `#d6261d`; Synq night `#0a0d10` / teal `#5eead4`. One accent per page. No gradients, no shadows, no hairlines, no glass.
- **Grid**: one frame, side gutter `clamp(20px, 5vw, 72px)`, max width 1600 px. Cards radius 32 px, buttons are flat pills.
- **Motion** (transform and opacity only, one rAF loop only while a section is on screen):
  1. hero lines rise on load; marquee of product names (CSS, 38 s loop);
  2. Kagezan stage: sticky pin, the gameplay loop scales from 52% to full width as you scroll while the giant 影斬 fades behind it;
  3. products section: sticky stacking cards;
  4. about statement lights up word by word;
  5. reveal-on-enter for blocks (staggered), hover lift on buttons and cards;
  6. video plays only while visible.
  `prefers-reduced-motion`: no marquee, no reveal travel, no scrub (video becomes a static 16:9 poster), statement fully lit.
- **Performance budget**: Lighthouse mobile >= 90 (measured 99 home, 99 Synq hub, 100 guides index, 95 article). No layout shift (CLS 0). Home transfer: HTML ~25 KB, CSS ~20 KB, JS ~6 KB, fonts ~45 KB for latin, video 1.2 MB (only fetched when near the viewport, `preload=none`), phone shots webp 20-30 KB each. Do not put `will-change` on the big stage layers (it pushed TBT to 650 ms).
- **Bilingual**: `html[lang]` + `data-lang-block` spans, same mechanism as the Kagezan pages, same `localStorage` key `synq-lang`. Default EN.

## 4. How to work on it

```
python3 tools/build_pages.py      # regenerate /, /synq, /synq/guides
python3 tools/sync_chrome.py      # re-apply header/footer (tools/chrome.py) to every page
python3 tools/preview.py 4173     # local preview that applies vercel.json redirects and rewrites
python3 tools/check_links.py      # hard-constraint URLs + every internal link/asset resolves
```

Shared chrome: `public/chrome.css`, `public/chrome.js` (loaded by every touched page). Class prefix `sq-` so it never clashes with legacy `styles.css`.
